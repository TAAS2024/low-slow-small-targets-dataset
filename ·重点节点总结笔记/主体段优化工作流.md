# 主体段优化工作流（Related Work / 文献综述段落）

> 创建：2026-08-15 · 触发背景：2.2 章节优化（发现 LayoutDiffusion / ObjectStitch 机制错误、5 条缺失引用、重复段 / 笔记段残留）
> 定位：本工作流是「引用核实工作流」的**上层**，覆盖"整个段落 / 小节"的优化；「引用核实工作流」负责"单条引用"的核实，两者配合使用。
> 铁律：**保留原文学术表述，不做词汇降级；只做必要修正（机制、结构、拼写、标点）。**

---

## 一、触发条件

- 优化论文某个"主体段"：Related Work 小节、文献综述段落、方法对比段。
- 涉及：引用核实 + 结构清理 + 表述规范 + 写回 docx。

## 二、五阶段流程

### 阶段 0 · 定位与提取
1. 用 python-docx 定位目标章节段落范围（`d.paragraphs[i].text` 打印 index）。
2. **完整提取原文到临时文件**（`open('/tmp/xxx.txt','w')`），再用 `file_reader` 读——避免终端输出被截断导致漏读。

### 阶段 1 · 引用核实（复用「引用核实工作流」）
1. 逐句提取正文提及的**方法 / 引用**。
2. 对照参考文献列表，区分：已有引用 / 缺失引用（正文提了、参考文献无条目）。
3. 对每条做**三维核实**（存在性 / 条目准确 / 正文描述准确）。
4. 工具链顺序：OpenAlex → DBLP（venue 权威）→ arXiv API（摘要 + comment 字段确认 venue）。

### 阶段 2 · 问题分类
| 类型 | 识别信号 | 处理 |
|---|---|---|
| **机制错误** | 正文描述 vs 摘要机制不符（如 "layout encoder" vs 实际 LFM+OaCA） | 按摘要重写 |
| **描述过窄** | 遗漏关键信息（如只写 "masks" 实际支持 points/scribbles/bbox） | 补全 |
| **缺失引用** | 正文提及、参考文献无条目 | 补引用（真实论文）或删提及 |
| **虚构引用** | 查无此论文 | 删除 |
| **扩展混淆** | 把框架内扩展当独立论文（如 Multi-ControlNet 是 ControlNet 一部分） | 明确为"框架内扩展"，不单列引用 |
| **结构冗余** | 重复段 / 空段 / "→ Gap:" 笔记段 / 草稿残留 | 删除 |

### 阶段 3 · 重写规范（表述策略）
1. **保留原文学术表述**：`paradigm / modalities / catalysed / fundamental / simultaneously / plausible / manual intervention` 等**不得降级**为口语词（key / approach / signals / led to / at once）。上一轮误把 "fundamental→key、paradigm→approach" 已被纠正。
2. **去破折号**：em dash（—）→ 括号 `()` 或逗号；en dash（–）→ 连字符 `-`（如 "scene–target" → "scene-target"）。
3. **统一英式拼写**：catalyse / harmonise / colour / behaviour / generalisable / whilst / labelled / modelled / analyse（不是 -ize / -or / -able / while / labeled / modeled / analyze）。
4. **机制修正**：方法的一句话描述必须忠于摘要，能逐句找到依据。
5. **补全 / 明确化**：描述过窄的补全条件类型；框架内扩展明确归属。

### 阶段 4 · 输出格式（呈现给用户确认）
按固定四段输出：
1. **完整原文 + 翻译**（一段一翻译，标题段也要译）。
2. **核实结果**（引用核对表 + 缺失清单 + 结构问题表）。
3. **需要用户核实的内容**（补引用策略 / 结构删除 / 修正文本是否采纳）。
4. **相关引用内容**（每条：完整条目 + 摘要关键句佐证/否定正文描述）。

### 阶段 5 · 写回 docx
1. 补引用：插入参考文献条目 + 编号重排。
2. 修正正文描述（只改需要修正的句子，不动其余）。
3. 删除冗余段落。
4. **先确认 Word 已关闭**（检测 `~$works-*.docx` 锁文件），否则写回失败。

---

## 三、写回 docx 技术要点（python-docx）

- 定位：`d.paragraphs[i]`，打印 index + 文本确定范围。
- 参考文献每条是 `w:hyperlink` 元素：
  - 改 URL：`p.part.rels[rid]._target = new_url`
  - 改文本：递归遍历 hyperlink 内 `w:r` 的 `set_text`
- 删段落：`p._element.getparent().remove(p._element)`
- 段落编号变化后需重新读取定位，不能沿用旧 index。
