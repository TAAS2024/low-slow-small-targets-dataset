## 零、写作规范（硬性要求，全文遵守）

### 0.1 三条铁律

1. **不分点式写作结构**：正文一律用连贯段落（prose）叙述，不用 bullet points / 编号列表堆砌。例外仅限：Contributions 编号、Algorithm 伪代码、公式、图表。
   - 例：介绍某个模块的三个作用时，写成一段话，而非三条并列短句。
2. **不用破折号**：不用 em dash（—）和 en dash（–）。用逗号、括号、冒号或拆句替代。
   - 例：「the framework, a dual-agent architecture, generates data」（逗号）而非「the framework — a dual-agent architecture — generates data」。
3. **英式英语**：全文 British English 拼写与用词，见下方对照表。

### 0.2 英式英语拼写对照（美式 → 英式）

| 美式 | 英式 |
|:--|:--|
| color | colour |
| behavior | behaviour |
| analyze | analyse |
| optimize / utilize | optimise / utilise |
| recognize / generalize | recognise / generalise |
| modeling / labeling | modelling / labelling |
| center / meter | centre / metre |
| program（一般义） | programme |
| traveling / canceled | travelling / cancelled |
| gray | grey |
| toward | towards |

> 注意：`computer program`（计算机程序）在英式英语中保留 `program`；`programme` 用于节目/计划。

| **RQ1** | How can the spatial location and scale of generated low-slow-small targets be precisely controlled without manual condition-map annotation? | §3.3 / §3.4，§5.1 |
| **RQ2** | How can the quality of generated data be automatically assessed across multiple pipeline stages? | §3.6，§5.2 |

## 三、§2 Related Work（四小节，每节末尾 → Gap）

**整体作用**：铺路，每节末尾批判 + 引出本文（引用内容详见 `00-论文写作-引用填充内容.md`）。

### 2.1 Synthetic Data Generation for Object Detection（RQ4）
GAN 时代（StyleGAN2-ADA [7]、DatasetGAN [51]、SYNTHIA [50]、Virtual KITTI [49]、Copy-Paste [9]）→ 扩散基座（SD [5]、DDPM [41]、DreamBooth [10]、Textual Inversion [11]、LoRA [39]）→ 面向检测生成（DetDiffusion [52]、InstaGen [14]、AeroGen [53]、ODGEN [54]、FLORA [15]、EgoGen [55]、DA-Fusion [12]）。
**末尾 Gap**：全图合成 / 无对象级控制 / 无跨模态。

### 2.2 Spatial Controllable Image Generation（RQ1）
ControlNet [6]、T2I-Adapter [18]、Uni-ControlNet [19]、GLIGEN [20]、InstanceDiffusion [21]、LayoutDiffusion [22]、LSeg [16]、SAM [33]、Depth Anything V2 [34]、DPT [35]。
**末尾 Gap**：都需手工画条件图 → 标记注入自动化。

### 2.3 Low-Slow-Small Target Detection（RQ4 downstream）
通用检测器（ResNet [1]、YOLO [2]、Focal Loss [3]、ViT [4]、YOLOX [27]、YOLOv7 [28]、RT-DETR [29]、YOLOv9 [32]）+ LSS 数据集（Anti-UAV410 [24]、DroneMMset [25]、Anti-UAV [26]）+ 无人机小目标（TPH-YOLOv5 [30]、Drone-YOLO [31]）。
**末尾 Gap**：无配对 RGB-IR；非 UAV 类别零数据集。

### 2.4 Quality Assessment and Closed-Loop Feedback（RQ2+RQ3）
CLIP [17]、SSIM [44]、MUSIQ [36]、ImageReward [37]、PickScore [38]、FID [45]、Score-SDE [40]、Progressive Distillation [43]、CycleGAN [23]、LoRA [39]。
**末尾 Gap**：无状态一次性过滤 → 失败归因 + 定向修正 + 课程硬化。

## 四、§3 The Proposed Method（全文核心）

### 3.1 Overview of the Generation Architecture
- **作用**：一图总览 + 双 Agent 对抗叙事定调。
- **内容**：架构全景图 + 三段文字（整体流程 / 标记注入创新 / 双 Agent 对抗训练范式），点明「Generator 内部 6 模块 + Validator 九阶段」。
- **图表**：Fig.2（架构全景图）。

### 3.2 LLM-Driven Semantic Parser（Generator Module 1）
- **作用**：入口模块，自然语言 → 结构化配置。
- **内容**：输入示例 → 双 JSON（`background_spec` + `full_scene_spec`）→ 三层解析回退 → 8 项默认值注入 → 12×6×8×8 枚举映射。
- **RQ**：RQ1（空间控制语义源头）。

### 3.3 Background Matching and Scene Extraction（Generator Modules 2–3）

#### 3.3.1 Real-World Background Pool Construction
37,852 张背景池（Pexels+Pixabay）、9 场景×3 时相×6 天气、CLIP 零样本分类、fallback 逻辑。**图表**：Fig.4。

#### 3.3.2 Depth and Segmentation Extraction
MidasDetector + HeuristicSeg（6 超类），注明升级路径 Depth Anything V2 + SAM2。

#### 3.3.3 Automated Marker Injection Strategy（核心创新）
对比表（全图合成 vs 贴入 vs 标记注入）+ **Eq.1–4**（Gaussian 软权重 / 深度物理混合 / seg 赋值 class_id=7 / 距离→深度映射）。**RQ1**。**图表**：Fig.3 + Eq.1–4。

### 3.4 LoRA-Based Drone Generation and ControlNet Repainting（Generator Modules 4–5）

#### 3.4.1 Drone LoRA Fine-Tuning
SD 1.5 基座、Pocket_UAV trigger、2000 step、123 张无人机图。**RQ4**。

#### 3.4.2 Silhouette Extraction and Marker Generation
LoRA txt2img → rembg → dilate → drone_clean(RGBA)。**RQ1**。

#### 3.4.3 ControlNet Dual-Condition Guided Repainting（核心）
五步管线 + **Eq.5–7**（去噪 / CFG / DDIM），强调局部重绘（blend_strength=0.65）。**RQ1**。**Eq.5–7**。

#### 3.4.4 Focus Rapid Repositioning Mechanism
跳过 LoRA+rembg，复用 drone_rgba 重定位（~30s→~5s），坐标转换表。**RQ1**。**Fig.5**。

### 3.5 RGB-to-IR Domain Conversion（Generator Module 6）
灰度→反转→三通道重建（B×0.85 微蓝调），**Eq.8–9**；解释伪彩色必要性（纯灰度致 VAE 坍缩）；诚实声明 colormap 非真实热辐射。**RQ4**。**Fig.6 + Eq.8–9**。

### 3.6 Nine-Stage Multi-Loop Quality Validation（Validator Agent）

> **九阶段 = V1–V9**：V1–V5 输入端拦截 + V6–V9 输出端审查。多样性约束（原 V10）归入 §3.7 课程硬化 L3，**不算独立验证阶段**。

#### 3.6.1 Input-Side and In-Generation Validation（V1–V5）
19 条规则检查表（V1 JSON 5 / V2 背景 3 / V3 depth-seg 4 / V4 LoRA 4 / V5 Focus 3）。**RQ2**。

#### 3.6.2 Output-Side Review（V6–V9）
V6 BRISQUE 质量 / V7 4D 一致性 / V8 轨迹物理 / V9 YOLO 检测 + short-circuit。**RQ2**。**Eq.10–14 + Algorithm 1 + Fig.10**。

### 3.7 Alignment Precision Assessment（对齐精度评估）
RGB→bbox / RGB→IR / 三元组一致性三个评估维度，作为闭环裁判的对齐精度信号源。**RQ1/RQ4**。

### 3.8 Multi-Loop Adversarial Feedback Mechanism（差异化核心）
失败码→模块路由表 / 三 Buffer（20/30/50）/ 五条对抗隔离铁律 / V8 双路径修复 / 课程硬化三层（L1 阈值递增 + L2 硬负样本 + **L3 多样性惩罚 V_diversity**）。**RQ3**。**Eq.15–16 + Algorithm 2**。

## 十、写作避坑清单

1. Related work 每段结尾批判 + 引出本文，不只罗列。
2. 公式后必有符号定义。
3. 表格后必有分析段落。
4. Introduction 先讲方法再列贡献。
5. Limitation 诚实声明，为未来造势。
6. 图表在正文至少引用一次。
7. 用「iterative quality bootstrapping」而非「continual learning」。
8. 强调「固定任务空间内的自主精炼」，人在环中做战略决策。
9. 不回避非 UAV 类别验证困难，坦诚定性展示 + UAV 强校准泛化。
10. **遵守 §零 写作规范**：不分点、不用破折号、英式英语。
