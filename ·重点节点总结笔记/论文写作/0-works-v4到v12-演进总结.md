## 四、观点与发现的变化

### 4.1 六项方向性反转

**① 「完整管线降低下游可检出性」→ 撤回，改为 null result（最重要）**

| | 旧 | 新 |
|:--|:--|:--|
| 数字 | `R_aerial` 0.153（管线）vs 0.540（硬粘贴），"3.5 倍" | `R_aerial` 0.540 vs 0.507，**p = 0.49** |
| 解释 | "视觉自然度 vs 目标显著性**方向相悖的权衡**" | "**二值代理分辨率不足，测不出差异**" |

**三层证据支持新结论**：
- 像素 / 边界层：LCR 1.655 → 1.338（p = 4.92 × 10⁻⁵）强显著
- 下游**连续** best_iou 配对 Wilcoxon：E4 both-vs-depth **p = 0.0017**、seg-vs-depth **p = 0.048**（可分辨）
- 二值 `R_aerial`：全部不显著（p = 0.12 ~ 0.82）

**根因**：COCO 二值背景假阳性率 6.7% ~ 32%，淹没了目标的 3–10 点贡献。
来源追溯：v8 的 `.153 vs .540` 是 halo 未修复时的**假差异**，被当成方向性发现。

> **红线**：不得声称完整管线提升下游可检出性，**亦不得**声称存在反向代价。

**② 「self-improving / 单调质量提升」→ stabilising**
A1 闭环实测 0.150 → 0.233 → 0.217 → 0.217（非单调平台）。A2/A3 是
"以**单位尝试产出率**换**目标达成率**的效率交换"（A2 达成 0.433 vs A1 0.150，但产出 0.136 vs 0.204），
**不构成能力提升**。禁用词：`converges` / `improves monotonically` / `progressive refinement`。

**③ 「跨模态一致率 100% 是成绩」→ 构造性性质**
原来是"confirmed exact spatial correspondence"。实为 `assumed=True` 的恒等 1.0。
现表述："**property of the transformation rather than an experimental measurement**"，不作性能指标。
计划书指标同步改为"IR 框须由**独立测量**给出"。

**④ 「LoRA 提升空间对齐」→ 负面结果照实报告**
E3：lora IoU **0.706** vs no-lora **0.744**。适配器反而略差，不声称增益。

**⑤ 「E4 双条件有增益」→ 无增益（且曾被写反）**
v7 把 BGE / LCR 的**负结果写成了正收益**，v8 修正。现在：E4 三臂空间指标
IoU 全 0.706、pos_err 全 1.252 —— **构造性绑定，零区分度**；差异只在边界融合 / 感知层面，且方向为负。

**⑥ 「背景池 28,000」→ 37,852**
审计证明全池 100% 来自无版权图库（pixabay 25,462 + pexels 12,097 = 37,559 条元数据），
不存在"有版权 / 无版权"二分；28,000 是 8-16 拍板时**主动改小**的概数，与管线自记录冲突。

### 4.2 三项事实性纠错

| # | 旧陈述 | 事实 |
|:--:|:--|:--|
| 1 | 「纯天空、城市占比**高于**乡村、机场」 | **相反**：pure_sky 2,695 最少；rural 5,091 第 3 多 |
| 2 | 「算法化采样 + 四约束坐标搜索（边距 / 间距 / 深度一致 / 边界净空）」 | `harness.py::plan()` 实为 `nu~U(0.12,0.88)`、`nv~U(0.10,0.68)` 随机分层，**无四约束** → 降级 + 转入 §6 |
| 3 | 「深度条件是 metric depth」 | **affine-invariant 相对（逆）深度**（MiDaS / Annotators ÷255） |

### 4.3 两项口径降级

- 「full **V1–V9** 链贡献 79.0% 降幅」→ 改为 **output-side V6–V9**（V1–V5 不在闭环判据内）
- 「§4.4 分阶段**准确率**」→ 降级为**存在性证据**（`tests/test_s*.py` + Demo，无分阶段检出计数）

### 4.4 新增的正面发现

- **§4.5.9 解析器基准**：字段级准确率 **0.985** / 完整 schema 匹配 **0.93**（vs 确定性模板 0.850 / 0.570）；
  非法输出 0/300；延迟 0.99–1.10 s。含三条诚实声明：OOV 子集 gold = 保守默认值（**结构性偏袒模板臂**）、
  模板臂共用同一受控词表（**不是独立工程基线**）、LLM 对确定项 100% 附注（过度标注）。
- **E5 轨迹一致性**：外观余弦 **0.322 ± 0.116** vs **0.051 ± 0.030**（≈ **6 倍**）—— 强证据。
- **E2 验证强度**：假接受率相对降低 **79.0%**（267/302 vs 56/302），Jaccard 0.201。
- **halo 修正**：ring Laplacian 方差中位 **1147 → 373（3.1×）**，饱和度 / 亮度偏差 → ~0。
