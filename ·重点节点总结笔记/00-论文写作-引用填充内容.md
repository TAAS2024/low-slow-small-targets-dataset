## 二、CHAPTER 2 Literature Review（核心填充）

### 2.1 Synthetic Data Generation for Object Detection（RQ4）

> 论证逻辑：GAN 时代 → 扩散时代 → 面向检测的专项生成，逐步暴露「全图合成 / 无对象级控制 / 无跨模态」三个 gap。

**（a）GAN 时代与合成数据先驱**

- **[7] StyleGAN2-ADA**（Karras et al., NeurIPS 2020）
  - 准确描述：提出自适应判别器增广，在**有限数据**下稳定 GAN 训练，无需改损失或架构。
  - 实例：CIFAR-10 上把 FID 从 5.59 提升到 2.42。
  - 引用点：代表 GAN 时代的小数据增广思路，引出"GAN 虽能造图但缺乏对象级控制"。

- **[51] DatasetGAN**（Zhang et al., CVPR 2021）
  - 准确描述：用 GAN 潜码解码为语义分割图，仅需少量人工标注即可生成"无限标注数据集"。
  - 实例：为 7 个分割数据集生成标注。
  - 引用点：早期自动标注范式，但只做**分割**不做**检测 bbox**，且依赖 GAN 不可控性。

- **[50] SYNTHIA**（Ros et al., CVPR 2016）
  - 准确描述：用虚拟世界自动生成带像素级标注的合成城市图像。
  - 引用点：合成数据先驱，但依赖 3D 图形引擎，非真实图像分布。

- **[49] Virtual KITTI**（Gaidon et al., CVPR 2016）
  - 准确描述：真实→虚拟世界克隆，自动标注检测/跟踪/分割/深度/光流。
  - 引用点：证明"虚拟数据预训练可提升真实性能"，但同样受限于图形渲染的真实性。

- **[9] Copy-Paste**（Ghiasi et al., CVPR 2021）
  - 准确描述：简单随机粘贴目标即强增广，无需建模上下文。
  - 实例：COCO 实例分割 49.1 mask AP / 57.3 box AP（+0.6 mask AP / +1.5 box AP）。
  - 引用点：**本文直接对标 baseline**——粘贴边缘生硬、光照纹理不一致，正是本文标记注入要解决的。

- **[8] Generative Modeling for Small-Data Object Detection**（Liu et al., ICCV 2019）
  - 准确描述：从生成建模视角处理小数据目标检测，在有限标注 bbox 下学习生成新训练图像。
  - 引用点：小数据检测的生成思路先驱，但无空间控制与验证闭环。

**（b）扩散模型基座与个性化**

- **[5] Stable Diffusion / LDM**（Rombach et al., CVPR 2022）
  - 准确描述：在预训练自编码器**潜空间**做扩散，大幅降低计算成本，跨注意力引入文本条件。
  - 引用点：本文 LoRA 基座模型（SD 1.5）。

- **[41] DDPM**（Ho et al., NeurIPS 2020）
  - 准确描述：去噪扩散概率模型，高质量图像合成。
  - 实例：CIFAR-10 FID 3.17。
  - 引用点：扩散模型理论基础（§3.4 重绘公式的源头）。

- **[42] Diffusion Models Beat GANs**（Dhariwal & Nichol, NeurIPS 2021）
  - 准确描述：分类器引导，扩散模型图像质量首次超越 GAN。
  - 实例：ImageNet 128×128 FID 2.97。
  - 引用点：论证扩散模型作为生成基座的优势。

- **[10] DreamBooth**（Ruiz et al., CVPR 2023）
  - 准确描述：少样本主体驱动个性化，把唯一标识符绑定到特定主体，可合成该主体在不同场景的新图。
  - 引用点：本文 LoRA 主体生成的替代路线（本文选 LoRA 而非 DreamBooth）。

- **[11] Textual Inversion**（Gal et al., ICLR 2023）
  - 准确描述：用 3–5 张图把新概念编码为 text embedding 中的"新词"。
  - 引用点：伪词注入思路，本文不采用，仅作对比。

- **[39] LoRA**（Hu et al., ICLR 2022）
  - 准确描述：冻结预训练权重，注入可训练低秩分解矩阵，大幅减少可训练参数。
  - 实例：相比 GPT-3 175B 全微调，可训练参数减少 10000 倍、GPU 内存降 3 倍。
  - 引用点：本文增量微调核心机制（LoRA-Buffer 触发的 LoRA 微调）。

**（c）面向检测的生成（与本文最相关）**

- **[52] DetDiffusion**（Wang et al., CVPR 2024）
  - 准确描述：首次协同生成与感知模型，通过分割引入**感知感知损失（P.A. loss）**提升生成质量与可控性，并从生成中提取感知属性做数据增广。
  - 引用点：布局引导生成的代表，但**无对象级空间精确控制**、无多模态。

- **[14] InstaGen**（Feng et al., CVPR 2024）
  - 准确描述：在扩散模型中集成 instance-level grounding head，对齐类别文本嵌入与区域视觉特征，生成样本增强检测器。
  - 实例：开放词汇检测 +4.5 AP。
  - 引用点：最近邻工作（instance-level 控制），但**无多模态、无验证闭环**。

- **[53] AeroGen**（Tang et al., CVPR 2025）
  - 准确描述：面向遥感目标检测的布局可控扩散模型，首个同时支持**水平 + 旋转 bbox** 条件生成。
  - 引用点：同属"布局可控检测数据生成"，但域在遥感，依赖布局标注而非自然语言。

- **[54] ODGEN**（Zhu et al., arXiv 2024）
  - 准确描述：基于 bbox 条件的域特定检测数据生成，用合成 visual prompts + 空间约束 + 对象级文本描述控制扩散模型。
  - 引用点：bbox 条件生成代表，但**一次性过滤**，无失败归因与闭环。

- **[15] FLORA**（Patrício et al., arXiv 2025）
  - 准确描述：仅用 Flux 1.1 Dev + LoRA 轻量微调的合成数据管线，消费级 GPU（RTX 4090）即可运行。
  - 实例：仅 500 张合成图训练检测器，胜过 5000 张的 baseline。
  - 引用点：低数据效率路线，与本文"穷尽生成规模"形成对照，且**无验证闭环**。

- **[55] EgoGen**（Li et al., CVPR 2024）
  - 准确描述：自我中心（第一人称）视角合成数据生成器，核心是人类运动合成模型 + 避碰运动原语 + 两阶段强化学习。
  - 引用点：视角驱动范式参考，说明"合成数据 + 特定视角"的价值，但域在 AR 自我中心感知。

- **[12] DA-Fusion**（Trabucco et al., ICLR 2024）
  - 准确描述：用预训练文生图扩散模型做图像到图像编辑，改变高层语义属性以增强数据多样性。
  - 引用点：扩散增广早期验证，仅少样本分类/杂草识别，无检测 bbox 控制。

**末尾 Gap 段落（引用支撑）**：
> 现有方法要么全图合成（DetDiffusion [52]）、要么布局/bbox 条件（AeroGen [53]、ODGEN [54]）、要么纯效率路线（FLORA [15]），但都缺乏**对象级空间精确控制 + 多阶段质量验证 + 失败闭环**，且**无双模态（RGB-IR）扩展**——这正是本文 RQ1/RQ2/RQ3/RQ4 要填补的空缺。

### 2.2 Spatial Controllable Image Generation（RQ1）

> 论证逻辑：从 ControlNet 到 layout/instance 控制，暴露「手工画条件图」这一核心瓶颈。

- **[6] ControlNet**（Zhang et al., ICCV 2023）
  - 准确描述：冻结大扩散模型，用零卷积（zero convolutions）连接可训练副本，学习多样空间条件（边缘/深度/分割/姿态）。
  - 引用点：本文核心机制基座（depth + seg 双条件）。

- **[18] T2I-Adapter**（Mou et al., AAAI 2024）
  - 准确描述：轻量适配器，冻结原 T2I 模型，对齐内部知识与外部控制信号。
  - 引用点：比 ControlNet 更轻量的替代方案，本文选 CN 因精度更高。

- **[19] Uni-ControlNet**（Zhao et al., NeurIPS 2023）
  - 准确描述：统一框架，同时组合局部控制（边缘/深度/分割）与全局控制（CLIP 图像嵌入）。
  - 引用点：多条件统一框架参考。

- **[20] GLIGEN**（Li et al., CVPR 2023）
  - 准确描述：grounded 生成，冻结权重，通过 gated 机制注入 bbox + 短语条件。
  - 引用点：开放集 grounded 生成，但**无法精细控制形状**（只给 bbox）。

- **[21] InstanceDiffusion**（Wang et al., NeurIPS 2024）
  - 准确描述：instance-level 控制，支持点/scribble/bbox/mask 多种位置指定。
  - 实例：COCO 上 bbox 条件 +20.4% AP50。
  - 引用点：单目标+场景融合的能力参考，但多实例复杂度高。

- **[22] LayoutDiffusion**（Zheng et al., CVPR 2023）
  - 准确描述：layout-to-image，用 Object-aware Cross Attention 精确控制多对象空间关系。
  - 引用点：布局驱动，但**不施加像素级空间约束**（无法精细控制形状）。

- **[16] LSeg**（Li et al., ICLR 2022）
  - 准确描述：语言驱动语义分割，文本嵌入与像素嵌入对齐，零样本泛化到未见类别。
  - 引用点：本文 seg 提取可参考的语义分割方法。

- **[33] SAM**（Kirillov et al., ICCV 2023）
  - 准确描述：可提示分割大模型，零样本泛化。
  - 实例：SA-1B 数据集 1B masks / 11M images。
  - 引用点：本文 seg 提取的升级路径（当前用 HeuristicSeg）。

- **[34] Depth Anything V2**（Yang et al., NeurIPS 2024）
  - 准确描述：用合成图替换真实标注图 + 大教师模型 + 伪标签，单目深度更细更鲁棒。
  - 实例：比 SD 基座模型快 10 倍以上。
  - 引用点：本文 depth 提取的升级路径（当前用 Midas）。

- **[35] DPT / Dense Vision Transformers**（Ranftl et al., ICCV 2021）
  - 准确描述：ViT 做密集预测骨干，单目深度估计相对性能提升最高 28%。
  - 引用点：本文当前 depth 提取模块（controlnet_aux 的 Midas 即基于此）。

**末尾 Gap 段落（引用支撑）**：
> 无论 ControlNet [6]、T2I-Adapter [18] 还是 GLIGEN [20]、LayoutDiffusion [22]，**都需要人工绘制或构造条件图（depth/seg/pose/bbox）**，这对需要成千上万张多场景、多天气、多轨迹图像的规模化数据集构建而言不可行。本文的**标记注入自动化条件图**正是为此而生。

### 2.3 Low-Slow-Small Target Detection（RQ4 downstream）

> 论证逻辑：交代下游检测现状 + 数据缺口（无配对 RGB-IR、非 UAV 类别空白）。

**（a）通用检测器**

- **[1] ResNet**（He et al., CVPR 2016）
  - 准确描述：残差学习框架，大幅加深网络。
  - 实例：152 层 ResNet 在 ImageNet 测试集 3.57% error，ILSVRC 2015 冠军。
  - 引用点：检测器 backbone 基础。

- **[2] YOLO**（Redmon et al., CVPR 2016）
  - 准确描述：把检测框定为回归问题，单网络端到端，45 FPS 实时。
  - 引用点：单阶段检测范式开端，本文 YOLO 系检测器的源头。

- **[3] Focal Loss**（Lin et al., ICCV 2017）
  - 准确描述：针对密集检测的前背景类别极端不平衡，提出 Focal Loss。
  - 引用点：小目标检测中类别不平衡的理论基础。

- **[4] ViT**（Dosovitskiy et al., ICLR 2021）
  - 准确描述：纯 Transformer 直接处理图像 patch。
  - 引用点：Transformer 检测器（RT-DETR）的理论铺垫。

- **[27] YOLOX**（Ge et al., arXiv 2021）
  - 准确描述：anchor-free + decoupled head + SimOTA 标签分配。
  - 实例：YOLOX-L 50.0% AP @ 68.9 FPS。
  - 引用点：YOLO 系演进节点。

- **[28] YOLOv7**（Wang et al., CVPR 2023）
  - 准确描述：trainable bag-of-freebies，实时检测 SOTA。
  - 实例：56.8% AP @ 30+ FPS。
  - 引用点：本文检测器 baseline 候选。

- **[29] RT-DETR**（Zhao et al., CVPR 2024）
  - 准确描述：首个实时端到端 DETR，用高效混合编码器去除 NMS。
  - 引用点：Transformer 检测替代方案。

- **[32] YOLOv9**（Wang et al., arXiv 2024）
  - 准确描述：可编程梯度信息（PGI）应对信息瓶颈。
  - 引用点：YOLO 最新演进。

**（b）LSS 数据集（数据缺口论证）**

- **[24] Anti-UAV410**（Huang et al., TPAMI 2024）
  - 准确描述：410 视频 / 438K 人工标注 bbox 的热红外无人机跟踪基准，提出 SiamDT 跟踪器（双语义特征 + 背景干扰抑制）。
  - 实例：410 序列 / 438K bbox，**纯热红外**。
  - 引用点：本文下游 mAP 评估主基准；论证"纯 TIR、无 RGB"的模态缺口。

- **[25] DroneMMset**（张峻宁 et al., ModelScope 2025）
  - 准确描述：面向低空无人机监测的多模态感知数据集（RF + RGB + IR + 飞控遥测）。
  - 引用点：论证"虽多模态但视觉 bbox 标注依赖 RF 定位转换、非精确视觉标注"的标注质量缺口。

- **[26] Anti-UAV**（Jiang et al., TMM 2023）
  - 准确描述：300+ 视频对 / 580K 人工标注 bbox 的视觉无人机跟踪基准，提出 DFSC 跟踪器。
  - 引用点：早期视觉 UAV 基准，论证数据规模有限。

**（c）无人机小目标检测**

- **[30] TPH-YOLOv5**（Zhu et al., ICCVW 2021）
  - 准确描述：YOLOv5 + Transformer Prediction Head + CBAM，针对无人机场景多尺度目标。
  - 引用点：小目标检测特化，可作对比。

- **[31] Drone-YOLO**（Zhang, Drones 2023）
  - 准确描述：基于 YOLOv8，三层 PAFPN + 大尺度特征图小目标检测头，专治无人机图像大场景/小目标。
  - 引用点：同领域检测器，可作对比。

**末尾 Gap 段落（引用支撑）**：
> 现有基准要么纯热红外（Anti-UAV410 [24]）、要么标注不精确（DroneMMset [25]），且**没有配对 RGB-IR**，非 UAV 类别（风筝/气球/飞艇）**完全无公开数据集**。本文通过生成像素级对齐的 RGB-IR-BBox 三图一体数据来填补这一缺口。

### 2.4 Quality Assessment and Closed-Loop Feedback（RQ2+RQ3）

> 论证逻辑：从图文对齐、图像质量评估到生成质量指标，暴露「无状态一次性过滤」的局限。

- **[17] CLIP**（Radford et al., ICML 2021）
  - 准确描述：4 亿图文对对比预训练，自然语言零样本迁移。
  - 引用点：本文背景匹配（V2）、多样性约束（V10）的评估基座。

- **[44] SSIM**（Wang et al., TIP 2004）
  - 准确描述：基于结构信息退化的图像质量评估。
  - 引用点：本文 V4 LoRA concept bleed 检测（SSIM vs 空白）的度量基础。

- **[36] MUSIQ**（Ke et al., ICCV 2021）
  - 准确描述：多尺度图像质量 Transformer，处理原生分辨率图像。
  - 引用点：无参考 IQA 的 SOTA，本文 BRISQUE 的替代/补充。

- **[37] ImageReward**（Xu et al., NeurIPS 2023）
  - 准确描述：首个通用文生图人类偏好奖励模型，137k 专家比较。
  - 引用点：人类偏好对齐评估，本文验证端可参考。

- **[38] Pick-a-Pic / PickScore**（Kirstain et al., NeurIPS 2023）
  - 准确描述：开放人类偏好数据集 + CLIP 基评分函数 PickScore，预测人类偏好超人类水平。
  - 引用点：生成质量评估参照，与人类排序相关性高。

- **[45] FID**（Heusel et al., NeurIPS 2017）
  - 准确描述：提出 Fréchet Inception Distance 衡量生成图与真实图相似度。
  - 引用点：本文生成质量主指标之一。

- **[40] Score-SDE**（Song et al., ICLR 2021）
  - 准确描述：SDE 统一框架描述前向加噪与反向去噪，predictor-corrector 采样。
  - 引用点：扩散模型理论统一（§3.4 公式背景）。

- **[43] Progressive Distillation**（Salimans & Ho, ICLR 2022）
  - 准确描述：渐进蒸馏把采样步数减半直至极少步。
  - 实例：从 8192 步蒸馏到 4 步。
  - 引用点：加速采样，本文生成效率的潜在优化方向。

- **[46] Inception**（Szegedy et al., CVPR 2016）
  - 准确描述：Inception v3 架构，FID/KID 的特征提取 backbone。
  - 引用点：FID 指标的组件引用。

- **[48] Adam**（Kingma & Ba, ICLR 2015）
  - 准确描述：自适应矩估计优化器。
  - 引用点：本文训练优化器。

- **[23] CycleGAN**（Zhu et al., ICCV 2017）
  - 准确描述：无配对图像到图像翻译，循环一致性损失。
  - 引用点：本文 RGB→IR 域转换的对照（本文用确定性伪彩色而非学习式翻译）。

**末尾 Gap 段落（引用支撑）**：
> 现有评估（CLIP [17]、ImageReward [37]、PickScore [38]）都是**无状态一次性打分**，只知"好坏"不知"哪里坏、该谁修"；而现有质量过滤（ODGEN [54]、FLORA [15]、InstaGen [14]）接受/拒绝整张输出，**无法把失败归因到具体组件**。本文的九阶段验证链 + 失败码路由正是对这一 gap 的正面回应（RQ2/RQ3）。
