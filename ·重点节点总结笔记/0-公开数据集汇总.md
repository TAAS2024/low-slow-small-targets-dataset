## 📌 当前框架（v4.3 单 LoRA + IR 转换）

```
DroneMMset RGB/IR 背景帧 ──→ 背景校验 Agent（正样本）
Anti-UAV-RGBT RGB/IR 帧 ──→ 背景校验 Agent（扩充）
DroneMMset 无人机裁切块 ──→ 无人机目标 LoRA ──┐
                                              │
                                    ControlNet 空间条件
                                         ↓
                                   无人机 LoRA 生成 RGB
                                         ↓
                                   rgb2ir_converter
                                    /              \
                                   RGB              IR (白热)
                                    ↓                ↓
                              背景校验 Agent ←── 正样本校准
                                    ↓
                    Stage 1 (CLIP) → Stage 2 (YOLO) → Stage 3 (IQA)
                                    ↓
Anti-UAV-RGBT RGB+IR ──→ 主验证集 (RGB+IR mAP)
Anti-UAV410 热红外  ──→ 辅助验证 (IR-only mAP)
                                    ↓
                              结构化报告 → 闭环反馈
```

- **IR 背景 LoRA 已废弃**：576 帧 IR 训练集转为背景校验 Agent 正样本
- **rgb2ir_converter**：`2-Lora training/rgb2ir_converter.py`（白热+微蓝调伪彩色）

**文件命名规范：**
```
drone_{摄像机}_{视频名}_{帧号}.jpg
例: drone_Cam01_Cam01-T0001-D00-A0001-S00_000000.jpg
     drone_Inf01_Inf01-T0001-D00-A0001-S00_000001.jpg
```

视频名解析：`{摄像机}-T{轨迹}-D{昼夜}-A{动作}-S{场景}`
- T: 轨迹编号 (0001~0111)
- D: 00=白天, 01=夜间
- A: 动作编号 (0001=悬停, 0010=俯仰, 0011=横滚, 0100=偏航, 0101=升降)
- S: 场景编号 (00~10，50m 和 200m 距离变化)

| 属性 | 值 |

| 采集视角 | 🔼 地面仰拍天空中的低空无人机 |
| 用途 | **主验证集**（RGB + IR 双模态 mAP）+ 背景 LoRA 扩充 + 无人机目标裁切 |
| 本地路径 | `0-database/Anti-UAV-RGBT/` |

**数据划分：**

| Split | 序列数 | 说明 |
|:--|:--|:--|
| train | 160 | 训练用（可裁切无人机目标做 LoRA） |
| val | 67 | 验证用 |
| test | 91 | 测试用 |

**序列结构（每序列一个文件夹）：**
```
20190925_101846_1_1/
├── visible.mp4      ← RGB 视频 (~50s, 1920×1080)
├── visible.json     ← RGB 标注 (gt_rect + exist)
├── infrared.mp4     ← 热红外视频 (~50s, 640×512)
└── infrared.json    ← 红外标注 (gt_rect + exist)
```

**标注格式：**
```json
{
  "exist":    [1, 1, 1, ..., 0, 0],   // 逐帧可见性 (1=可见, 0=消失)
  "gt_rect":  [[x,y,w,h], ...]         // 逐帧 bbox
}
```

**属性标签（318 序列均标注挑战类型）：**

| 属性 | 含义 | 序列数 | 难度 |
|:--|:--|:--|:--|
| TC | Thermal Crossover 热交叉（总） | 192 | — |
| TC-EASY | 热交叉-简单 | 88 | ⭐ |
| TC-MID | 热交叉-中等 | 72 | ⭐⭐ |
| TC-HARD | 热交叉-困难 | 32 | ⭐⭐⭐ |
| FM | Fast Motion 快速运动 | 122 | ⭐⭐ |
| LI | Low Illumination 低光照 | 117 | ⭐⭐ |
| SV | Scale Variation 尺度变化 | 69 | ⭐⭐ |
| LR | Low Resolution 低分辨率 | 48 | ⭐⭐⭐ |
| OV | Out-of-View 出视野 | 39 | ⭐⭐⭐ |
| OC | Occlusion 遮挡 | 12 | ⭐⭐⭐ |

> **核心价值**：Anti-UAV300 是目前唯一同时提供 RGB+IR 全配对的 Anti-UAV 数据集。与 IR-only 的 Anti-UAV410 互补——300 可验证生成 RGB 图像的质量，同时验证 IR 域的保真度。TC（热交叉）是热红外特有的挑战：目标温度与背景接近时难以区分，192 序列覆盖了简单到困难三个等级。

**在框架中的定位：**

| 角色 | 具体用法 |
|:--|:--|
| 🔍 **主验证集** | 下游 YOLO 在 RGB 和 IR 双模态上的 mAP 评估，按属性分层报告（能看出 LoRA 生成对 TC/FM/LI 等难例的改善） |
| 🎯 **无人机目标 LoRA 补充** | 从 318 序列 × ~933 帧中裁切无人机区域，补充 DroneMMset 之外的视角/背景多样性 |
| ✅ **RGB 生成质量校验** | Anti-UAV410 只有 IR，300 的 RGB 分支可以验证 RGB 背景 LoRA 的生成质量 |

## 二、已删除数据集及删除原因

| 数据集 | 原始用途 | 删除原因 |
|:--|:--|:--|
| **COCO-Stuff** | ControlNet 分割图布局训练 | 新架构不再使用 ControlNet-Seg，无布局训练需求 |
| **SIDBench** | Stage3 伪影检测参考 | 三 Agent 验证链已覆盖图像质量检测，独立框架冗余 |
| **RGBTDronePerson** | RGB-T 配对目标检测 | 🔽 **无人机俯拍地面人群**，视角与地面仰拍完全相反，训练即污染 |
| **VTUAV-det** | RGB-T 配对目标检测 | 🔽 **无人机俯拍地面目标**，视角污染 |
| **UAV-RGB-T-2400** | RGB-T 配对目标检测 | 🔽 **无人机俯拍**，视角污染 |
| **官方数据集** | 原始参考 | 仅 ~68MB 参考用，已无实际用途 |

> **核心教训**：无人机检测 ≠ 低慢小目标数据集。大部分公开 RGB(-T) 数据集是无人机作为**采集平台**（俯拍地面），而非无人机作为**被观测目标**（地面仰拍天空）。只有 DroneMMset 和 Anti-UAV 系列是后者。
