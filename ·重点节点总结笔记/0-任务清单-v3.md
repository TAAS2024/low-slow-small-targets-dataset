## 三、课程硬化 + 闭环反馈（论文核心卖点）— 优先级 P0

> 这是论文区别于 ODGEN/FLORA/InstaGen 的核心创新，也是当前「方案设计完成、代码为零」的最大空白。

### 3.1 课程硬化三层机制

- [ ] **3.1.1 L1 阈值自动递增**（ThresholdEscalator：V2/V4/V6/V7 阈值 + 物理边界 + 回滚）
- [ ] **3.1.2 L2 Hard-Negative 重校准**（borderline 收集 >100 条 → 人工打标 → EfficientNet 增量微调）
- [ ] **3.1.3 L3 V_diversity 多样性惩罚**（CLIP 特征 + FAISS 检索，`V10_MODE_COLLAPSE` 失败码）
- [ ] **3.1.4 硬化调度器集成**（validator_pipeline 新增 run_epoch：生成→验证→L3→L1→L2 收集）

### 3.2 闭环反馈路由

- [ ] **3.2.1 三 Buffer 实现**（LoRA-Buffer 阈值 50 / CN-Buffer 30 / LLM-Buffer 20）
- [ ] **3.2.2 失败码 → 模块路由表**（12 个失败码精确分派到 Agent 1/3 子步骤）
- [ ] **3.2.3 LoRA 增量微调脚本**（Kohya 增量，lr=1e-6，400 步，A/B 评估后替换）
- [ ] **3.2.4 CN-LoRA 对比微调**（范式 B，失败 vs 修复对比对，rank=4）
