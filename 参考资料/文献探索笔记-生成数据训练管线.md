## 一、扩散模型生成检测训练数据（核心对标）⭐⭐⭐⭐⭐

### [1] ODGEN: Domain-specific Object Detection Data Generation with Diffusion Models

| 属性 | 详情 |
|------|------|
| **作者** | Jingyuan Zhu, Shiyu Li, Yuxuan Liu, Ping Huang, Jiulong Shan, Huimin Ma, Jian Yuan |
| **发表** | NeurIPS 2024 |
| **arXiv** | [2405.15199](https://arxiv.org/abs/2405.15199) |
| **代码** | [Apple ML Research](https://machinelearning.apple.com/research/odgen) |
| **相关性** | ⭐⭐⭐⭐⭐ |
| **参考功能** | 扩散模型生成检测数据 → YOLO 训练 → 验证提升 |
| **说明** | 与 CDFF 最接近的工作。给定领域检测数据集，先微调扩散模型（裁剪前景+全图），再用 box-conditioned 生成合成图像。在 7 个领域基准上 YOLOv5/v7 提升最高 **25.3% mAP@.50:.95**。设计了一个完整的 dataset synthesis pipeline。**关键区别**：ODGEN 用 box-conditioned 生成，CDFF 用 ControlNet+LoRA 条件生成；ODGEN 不涉及跨模态（RGB→IR）。 |

### [2] FLORA: Efficient Synthetic Data Generation for Object Detection in Low-Data Regimes via finetuning Flux LoRA

| 属性 | 详情 |
|------|------|
| **作者** | Alvaro Patricio, Atabak Dehban, Rodrigo Ventura |
| **发表** | arXiv 2025.08 |
| **arXiv** | [2508.21712](https://arxiv.org/abs/2508.21712) |
| **代码** | 待确认 |
| **相关性** | ⭐⭐⭐⭐⭐ |
| **参考功能** | LoRA 微调扩散模型生成合成数据 |
| **说明** | **与 CDFF 技术路线高度一致**。使用 Flux + LoRA 在消费级 GPU（RTX 4090）上生成合成数据，**仅 500 张合成图像**即可超越 ODGEN 的 5000 张基线（+21.3% mAP）。证明「质量优先于数量」的策略有效。CDFF 的 LoRA 微调策略可直接对标此工作。 |

### [3] InstaGen: Enhancing Object Detection by Training on Synthetic Dataset

| 属性 | 详情 |
|------|------|
| **作者** | Chengjian Feng, Yujie Zhong, Zequn Jie, Weidi Xie, Lin Ma |
| **发表** | CVPR 2024 |
| **arXiv** | [CVPR 2024](https://fcjian.github.io/InstaGen/) |
| **代码** | [GitHub](https://github.com/fcjian/InstaGen) |
| **相关性** | ⭐⭐⭐⭐⭐ |
| **参考功能** | 扩散模型同步生成图像+检测框 |
| **说明** | 在预训练扩散模型中集成 instance-level grounding head，使其能同时生成图像和物体边界框。创新点：使用现成检测器做监督 + 对 novel categories 进行 self-training。在 open-vocabulary（+4.5 AP）和 data-sparse（+1.2~5.2 AP）场景均有效。**对 CDFF 的参考价值**：CDFF 的 Agent 1 输出描述了轨迹和相机位置，若类似 InstaGen 同步生成 bounding box 标注，可省去后续手动标注环节。 |

## 六、CDFF 与现有工作的差异化定位

| 维度 | 现有工作 | CDFF |
|:--|:--|:--|
| 输入 | 检测数据集 / 类别标签 | **自然语言场景描述** |
| 条件控制 | Box / Mask / Text | **LLM 语义→JSON→ControlNet seg+depth** |
| 模态 | 仅 RGB | **RGB + IR 双模态** |
| 目标物体 | 通用物体 | **低慢小无人机（专用域）** |
| 生成方法 | Box-conditioned 扩散 | **ControlNet + LoRA + CN-LoRA 对比微调** |
| 反馈优化 | 无 / 离线 | **闭环自训练循环（S0-S3 验证→Buffer→微调）** |
| 计算效率 | 需全量微调 / 企业级 GPU | **LoRA rank=4，消费级 GPU 可运行** |

**核心差异化优势**：CDFF 的「自然语言→场景→多模态」管线在现有工作中没有直接对标——现有工作要么是 box-conditioned（ODGEN/InstaGen），要么是单模态（FLORA）。CDFF 的闭环自训练反馈也是独特之处。

## 七、搜索缺口（后续需要补搜的方向）

1. **无人机/UAV 专用合成数据**：目前未找到专门针对无人机检测的扩散模型生成工作（可能该交叉领域论文较少，需用 "UAV detection synthetic data" 深入搜索）
2. **IR 红外生成数据**：RGB→IR 模态转换 + 生成数据训练的联合工作几乎空白——这是 CDFF 的独特贡献点
3. **闭环反馈优化生成**：主动学习 + 扩散模型的结合（[4] 已涉及，但针对检测任务的较少）
4. **生成数据训练 YOLO 的系统性对比**：不同生成策略（ControlNet vs Box-conditioned vs Inpainting）对检测精度的影响对比实验
